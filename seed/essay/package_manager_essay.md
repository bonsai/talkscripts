# winget / choco / scoop / APT — パッケージマネージャ四種盛り

パッケージマネージャとは、ソフトウェアのインストール・更新・削除をコマンド一行で済ませる仕組みである。Windows には競合する三つの選択肢があり、Linux には APT がある。それぞれの哲学と実用性を比較する。

---

## APT — 王座

APT (Advanced Package Tool) は Debian/Ubuntu の標準パッケージマネージャである。`apt install ghostscript` の一行で、依存関係をすべて解決した上でインストールが完了する。リポジトリは世界最大級で、ほとんどの OSS が公式パッケージとして登録されている。

APT の強みは **「ただ動く」** ことだ。サードパーティのリポジトリを追加する必要がほとんどない。パッケージは `.deb` 形式で配布され、依存関係の解決は dpkg と apt の自動解決に任せられる。

しかし APT は Windows では動かない。WSL の中で使うことになる。

---

## winget — 純正

winget は Microsoft 純正のパッケージマネージャである。Windows 11 および Windows 10 (2022 以降) に標準搭載されている。

最大の利点は **「追加インストール不要」** であること。PowerShell を開いてすぐに `winget install` が使える。

しかし登録パッケージ数はまだ限定的で、特に「古くてニッチなツール」は登録されていない。先日 Ghostscript をインストールしようとして発覚したが、winget で見つかるのは `Ghost Trap` というまったく別のソフトだった。

winget のリポジトリは Microsoft Community Package Manifest Repository で管理されており、誰でもパッケージを追加申請できる。しかし審査に時間がかかる。

---

## choco — 老舗

Chocolatey (choco) は 2011 年からある Windows 向けパッケージマネージャの老舗である。`choco install ghostscript` と打てば、公式の NuGet フィードから自動でインストールされる。

choco の強みは **「パッケージ数の多さ」** と **「サイレントインストール」** にある。多くの Windows ソフトがサイレントインストールに対応しており、choco はそれをラップして統一インターフェースを提供する。

ただし欠点もある。**管理者権限が必須**であること。さらに、インストールの裏では本体のインストーラ (`.exe` や `.msi`) が実行されているだけであり、パッケージ管理の「純粋さ」は APT に劣る。アンインストールも、choco 経由でインストールしたことを覚えているかどうかに依存する。

あと、自動ホットキー入力の `autohotkey.portable` が依存関係として暗黙にインストールされることがあり、不意に AHK が入る。

---

## scoop — クリーン

scoop は 2015 年ごろからある Windows 向けパッケージマネージャで、**「管理者権限不要」** を謳っている。インストール先はユーザーフォルダ内 (`~\scoop`) であり、システム領域を汚さない。

また、ポータブルアプリを前提としているため、`scoop install ghostscript` で入れたツールは `scoop uninstall ghostscript` で完全に消える。レジストリを汚さない。

scoop のもう一つの特徴は **「バケット (bucket)」** というリポジトリ単位の管理である。標準の `main` バケットには CLI ツールが中心で、GUI アプリは `extras` バケットを追加する必要がある。

---

## 比較

| 項目 | winget | choco | scoop | APT |
|---|---|---|---|---|
| 権限 | 不要（一部要管理者） | **管理者必須** | **不要** | 要 sudo |
| インストール先 | Program Files | Program Files | `~\scoop` | `/usr/bin` |
| パッケージ数 | △ 少ない | ○ 多い | ○ CLI 豊富 | ◎ 最大級 |
| ポータブル | 不可 | 不可 | **可** | 不可（Linux標準） |
| Windows 標準搭載 | **はい** | いいえ | いいえ | なし (WSL/別OS) |
| 依存管理 | ○ | ○ | ○ | **◎ 完全自動** |
| アンインストール | ○ ただし標準 | △ 独自管理 | **◎ 完全削除** | ◎ 完全削除 |

---

## 結局どれを使うべきか

チョイスの基準は単純だ。

- **標準で動いてほしい** → winget
- **古いソフトやマイナーなソフトを入れたい** → choco（管理者権限が必要なら）
- **管理者権限なしでクリーンに使いたい** → scoop
- **Linux 上の開発** → APT（または新しいものなら `brew` も視野に）

ただし、Windows におけるパッケージ管理の最大の課題は **「どのマネージャで入れたか忘れる」** ことである。`winget` で入れたのに `choco uninstall` しても消えない、といった混乱が起きる。

理想は **一つのマネージャに統一すること** だが、現実的には winget で足りないものを scoop で補う、という二刀流が最もストレスが少ない。

---

*参考: 今回の Ghostscript インストール顛末*
- `winget search ghostscript` → ❌ `Ghost Trap` という別ソフトしか出ない
- `choco install ghostscript` → ❌ 管理者権限不足で失敗
- `scoop install ghostscript` → ❌ scoop 未インストール
- 結局、公式サイトから直ダウンロード → ❌ 管理者権限不足でインストーラ実行できず
- **結論: 管理者権限があれば choco 一発**
