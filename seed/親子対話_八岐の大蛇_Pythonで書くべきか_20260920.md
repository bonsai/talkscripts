# 親子対話：八岐の大蛇 — Python で書くべきか問題

父「なあ娘よ。おまえが『八岐の大蛇』って名前のプロジェクトを作ったと聞いてな。**大蛇だろ？ 蛇だろ？ Python だろ！** もう言語は決まりじゃないか🐍」

娘「……父さん。そのへんの判断、**タイポグリセミア**って言うんだけど」

父「なんだそれ。いや違う、理屈の前にだな。名前が『大蛇』で、蛇＝Python、これはもう世界がそう仕組んでる」

娘「確かに Boa(大蛇)は Python だけど、**プロジェクトの言語を干支で決めるのは最初の一歩の踏み外し方**だよ😅」

## 八岐の大蛇って、実はどんな料理を作ってるの？

父「じゃあお前の大蛇は、何を作るプロジェクトなんだ？」

娘「8つの頭を持つ大蛇——プロジェクトの**8つの作業面（Repo、Issue、PR、Action、Deploy、Chat、Data、World）**を、1つの料理として、あー、もっと料理で言うと『1つの鍋に全部の具材を揃える』やつだよ」

父「つまり、パラパラに散らかった具材を、ひとつの大きな鍋に集める料理、と」

娘「そう。しかも火（AI）が勝手に混ぜてくれて、完成したらレシピ（GitHub）に書き戻す。**今のところこの鍋は TypeScript + Deno 製**なんだ」

父「へえ。なんでだ？ Python のほうが有名じゃないか」

## 娘が最初に一言定義（料理メタファー）

娘「言語選びはね、料理で言うと**『何の火で、誰が毎日切るか』**の話だよ。食材の名前で包丁が決まっちゃうわけじゃない」

父「ゴボウが出るからゴボウ用の包丁を買う、みたいなのは違う、と」

娘「そうそう。まず『誰がこの厨房に立つか』『何を一番回すか』を決めないと、包丁も鍋も買えない😎」

## なぜ今は TypeScript + Deno なのか

父「で、お前はなんでその鍋にしたんだ？」

娘「**根っこが Chrome 拡張（JavaScript）だから**。言語が1つ、ランタイムが1つ、拡張も CLI も API も MCP も**同じ型を共有できる**んだよ。拡張とサーバで型がズレる心配が無い。あと Deno は説明書（package.json の地獄）が要らなくて、水筒サイズのコンロで回る」

父「本体が軽いと。それって、『同じレシピを厨房と出前先で共通で持てる』って感じか」

娘「うん。しかも今はまだ小さくて、こんな鍋1つしかない。**小さいうちは、道具を替えるのは簡単**なんだよ」

## でも Python にも、ゆるせない良さがある

父「じゃあ Python は駄目なのか？」

娘「駄目じゃない。むしろ**全部が聴こえるくらい魅力的**なんだよ。俺、今まで作ってきた道具のほとんどが Python なんだ——はいはい、まあ自分の料理人は『おまえ、包丁は全部Pythonだろう』って言いそうなくらい」

父「おお、慣れてる包丁ってことか」

娘「そう。ブラウザを操る（CDP/playwright）、Web の API を立てる（FastAPI）、エージェントとつなぐ（MCP）——**どれも Python の方が道具が揃ってて、俺の手になじんでる**。つまり『道具の腕前』で言ったら Python の勝ちかもしんない😉

ただ——」

## ここが本当の話

父「ただ、なんだ？」

娘「**言語を変えたところで、大蛇の『8つの頭』は1つも動かない**のよ。今の大蛇は『頭をどう振るか』（collect→operate→return）の構想が先にあって、実体がまだ尻尾しか無い。焦って Python に書き直すのは、**『包丁を取り替えてる間に、カレーが煮込まれてるのを忘れてる』**みたいなもん」

父「つまり、順番が違うってことか。ええと……最初に大事なのは、まず**料理を作ること**か」

娘「そう。しかも大蛇は、**頭を切り落とされても再生する**んだよ。話の本筋みたいに。だから後から『やっぱりこの頭は Python で生えさせよう』って、**一つの頭（たとえばブラウザ操縦の部分）だけ Python の頭に生え変わらせる**のは、大蛇の個性として十分あり得る」

父「じゃあ結論、どうすりゃいい」

## つまり…は…

父「つまり——**言語は『大蛇の名前に釣られて決めるものじゃない』**、と。まず鍋を火にかけて（object的な最初のゴールを通して）、動いてから、あの頭だけ Python に生え変わらせると、と」

娘「そういうこと😎 八つの頭で悩むより、**八つのうち一番必要になってから生やせばいい**。大蛇は頭が幾つあっても困らないからね。名前の通りに🐍」

父「……最初から Python でよかったんじゃないかって気もするが、まあ、お前の頭の中じゃあ、いま Python の頭がひとつ生えてきたってことで、それでいいわ」

娘「それそれ、それで行こう😄」
