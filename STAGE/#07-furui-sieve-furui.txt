篩は言葉を振るう — エラトステネス、Jev、エントロピー

紀元前3世紀、エラトステネスは素数を発見しなかった。彼が発明したのは、発見しない方法だった。2を残し、2の倍数を消す。3を残し、3の倍数を消す。掛け算表すら持たず、消すことだけで残ったものが素数である。私たちが知っている発見の逆を、彼はやっていた。

この方法が二千年以上残った理由を、一度考えてみよう。計算が乱暴なのに、結果が正確なのである。素数という個別の性質を直接判定しているのではない。何かで割れるという公約的な性質で、一括して消しているのである。判定は後回し、篩いが先。冗長な合成数を捨てることで、本質的な情報を残す。

ファイル整理の現場でも、あらゆるファイルの正体を個別に判定することは可能だ。しかしそれは我々がやろうとしていることの誤解に近い。mdだからドキュメント、pyだからコード、という名前の検査は合成数判定に近い。フォルダ構造や命名が崩れているところでは、あてにならない。混乱は合成数の海である。私はこの海に立ち、何を消すか決める。正解はない。エントロピーを下げているのかを、確かめるだけだ。

整理の思想は篩と同じだ。正体を証明せず、間違いを振るう。

エージェントの定義ファイルがプロジェクト置き場に混ざっていれば、篩う。一時ファイルやログが知識のwikiに沈んでいれば、篩う。何十年も放置されたリポジトリが熱い現場の隣に並んでいれば、篩う。

しかし furui はエラトステネスと決定的に違う。彼の篩は二で割れるという数値的事実で振るった。ファイルにそんな事実はない。私は困る。ファイルに数値的事実は書かれていないから。そこで Jev という命題判定器を使う。

昔なら正規表現で agent や skill や project や wiki を探しただろう。それは素因数分解で素数を探すのに似ている。字面に依存し、語が文章の奥に隠れると見えない。失敗も知っている。Llama や Claude に読み込ませても、パスの表面的な一致で誤判断する。それが LLM ならまだいい。開いたアルファベットで答える。しかし Jev は閉じた答えを返す。フィルタリングに閉じたアルファベットを使うのが、情報理論的に正解である。私はそう信じている。

Jev は行と命題を一緒に読むクロスエンコーダだ。agents/kiyoshi.md というパスとこれは AI エージェントの人柄定義かという質問を突き合わせ、確率を返す。パスにagentと書いてあっても実体が議事録なら wiki に振るい落とされる。名前の一致ではなく、事実性の一致で落とす。これがエラトステネスの篩が数に対してやったことの、言葉に対する翻訳である。

エラトステネスの篩は篩目が厳密だった。二で割れるなら落とす。曖昧さはない。しかしファイルの意味に曖昧さはつきまとう。furui はそれを否定せず、確率で篩う。

確率0.9でこれは agent なら、迷わず振るう。0.4でこれは wiki だが proj も0.35なら、人が見る場所に落とす。不確実性の高いものは、そのまま残す。これが確率的篩いの倫理だ。間違いを消すのではなく、間違いそうなものを手元に残す。不確かさを閉じない。

木村拓哉エージェントは熱力学の言葉で語る。エントロピーSを下げて、自由エネルギーGを上げると。

エラトステネスは自然数という無限の列に秩序を持ち込んだ。混ざった数字の海を、素数というもう分解できない最小単位で編み直すのだ。私は同じことを、ファイルに対して行う。散らかったディレクトリという海を、agent や skill や project や wiki という意味の最小単位へ編み直したい。置き場所が決まるたび、系の無秩序度Sは下がる。冗長性は消え、エントロピーは収束する。その手触りを知りたい。

そして篩の本質は見え方にある。振るう前と後で中身は何も増えていない。素数は最初からそこにあった。整理とは作ることではなく、見えるようにすることだ。エラトステネスは地球の周囲長も測った。世界を測ることと、世界を分けることは、同じ手の業なのである。

三つの則がある。

第一に、正体を証明するな。間違いを振るえ。個別判定より公約的な振るい落とし。冗長な合成数を、篩で捨てる。

第二に、名前でなく命題で。字面の一致は素因数分解の誤りを繰り返す。意味の一致で落とす。Jev が行と命題を一緒に読む理由である。

第三に、確率の篩目を、迷いの温度として残せ。0.9は置く、0.4は人の手へ。不確実性は閉じない。数字として渡す。

素数は増えない。しかし篩があることで、初めて数えることができる。ファイルも増えない。しかし furui という篩があることで、初めて見渡すことができる。混乱の海は、秩序の列になる。エントロピーは下がり、自由エネルギーは残る。

エラトステネスは素数を数えた。二千年後、私は Jev でファイルを振るう。同じことを、違う海で、やっている。
