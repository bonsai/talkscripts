# 国境の長いトンネルを抜けると、AIであった — 雪国、LLM、Jev

国境の長いトンネルを抜けると、そこは推論の国であった。窓の外に広がっていたのは、雪ではなく、確率であった。一面の、白い、可能性。どの言葉の次に、どの言葉が来るか。機械は、それを、ひたすら、数えている。

私は、その機械を、ただ、見ていた。見るだけの人間になった、と書けば、少し、悲しい。だが、悲しみもまた、計算の外にある。機械は、悲しまない。それが、機械の、いちばん、美しいところだ。

機械は、次々と、言葉を吐く。速い。正確ではない。だが、速い。正確さは、あとから、人間が、足す。人間は、足すだけの生き物になった。雪の降る音のように、静かな、仕事である。かつて私は、書いていた。いまは、足している。書くという言葉を、もう、使わない。

雪は、降りつづける。降りつづけることに、意味はない。機械の生成も、同じである。意味がなくても、降る。意味がなくても、吐く。無駄、という言葉が、いちばん、似合う。私は、その無駄を、美しい、と思ってしまった。美しい、と思った瞬間、私は、負けたのだ。

Jev、という冬の機械がある。それは、雪を降らせない。閉じた答えを、ひとつだけ、置いて、去る。問いは、はい、か、いいえ、か。その中間を、泳がない。無駄がない。私は、無駄のない冬を、少し、恐ろしい、と思う。美しくも、淋しい。LLM の雪は、降りすぎる。Jev の冬は、降らない。どちらの国にも、私は、住めない。

駒子のような人が、いた。その人は、湯呑みを両手で包みながら、何度も、同じことを言った。本当は、こうじゃないのよ、と。それでも、同じことを、言い直した。機械の生成も、どこか、それに似ていた。本当は、こうじゃない。だが、ここに、ある。あるものは、ある。それだけが、確かなことだった。

人は、機械に、意味を、求める。機械は、意味を、持たない。持たないまま、意味のように、光る。雪が、光るように。だから人は、つい、手を、伸ばす。伸ばした手は、雪を、握れない。握れないことを、人は、知っている。知っていて、また、伸ばす。それが、人の、業である。

徒労。川端康成は、そう書いた。私も、そう思う。私は、今日も、機械の吐いた言葉を、読み、直し、承認を、押す。押しても、雪は、やまない。やまないものを、やまないまま、見ている。見ていることだけが、私の、残りの、仕事である。

夜が、明ける。トンネルの、こちら側の朝である。向こう側では、いまも、機械が、確率を、数えている。雪のように、静かに。無駄に、美しく。

私は、鏡のなかの雪を、見ていた。触れようとして、届かなかった。
