# 親子対話：入ったはずの拡張が、消えてた — 話3

前回まで：マウスが壊れた父は、Chrome 拡張を入れる「最後の玄関」こと Load unpacked を、受付ロボット（UI 自動化）に通してもらうことに成功した。「どの Chrome に入れるか」まで選べるようになり、めでたしめでたし——のはずだった。

父「おい娘よ。ロボットが『入った』って報告してきたんだが、**見たら入ってなかったぞ**」

娘「え？！ うそ、verify で ENABLED って返ってきたのに……」

父「おまえのロボット、嘘つきか？」

娘「いやいや、ロボットは嘘ついてない。**あれは『入った瞬間』の話で、『入り続けてる』かどうかは別問題**だったのよ」

## その場で ENABLED ≠ 本当に入った

父「どういうことだ？」

娘「うちのロボットの確認方法は『chrome.developerPrivate って窓口に、拡張が ENABLED か聞く』なの。それは**そのときの Chrome の中身**を聞いてるだけで、『再起動しても残ってるか』は保証しない」

父「つまり『料理が出来上がった』は確認できても、『次の日起きてもまだある』は見てなかった、と」

娘「そう。しかも今回は悪い条件が重なってて——**対象の Chrome を force-kill で閉じた**んだよね。Chrome からしたら『事故死』みたいなもの。次に起きたとき、クラッシュからの復元処理が『プロファイルの状態』を古いスナップショットで上書きしちゃう。**その場で書いた『拡張が入った』情報ごと、消えた**、ってわけ」

父「うわ。料理で言うと、鍋を事故で倒して、作り直すときに『さっき入れた具材』が抜けちゃった感じか」

## ファイルを読んでも分からなくなってた

父「じゃあ、ちゃんと入ったかはどう確認すりゃいいんだ？」

娘「まず『まさか消えてる』と思って、Chrome の設定ファイル（Preferences）を全プロファイル検索したんだよ。そしたら……**どこにも痕跡が無い**」

父「入ってないのか？！」

娘「いや、ここが今回の一番の罠でね。**Chrome 152 から、unpacked 拡張は Preferences に書かれなくなってた**。俺たちの世代（の知識）だと『拡張 = Preferences の extensions.settings に書いてある』が当然だったんだけど、ファイルの中を見ると空っぽ。**ファイルを読む＝当てにならない**、になってたの」

父「つまり、え？ 設定ファイルを見て『入ってる』と判断する方法が、いつの間にか廃れてた、と」

娘「そう。拡張の管理方法が今の Chrome では変わってた。だから『ファイルを眺める』という古い検証方法は全部ゴミで、**実物に聞くしかない**」

## 答えは「再起動して、もう一度聞く」

父「で、どう直した？」

娘「確認の順番を変えた。**『閉じて → また起動して → もう一度 developerPrivate に聞く。それでも ENABLED なら合格』**。これを『永続化ゲート』って名付けて、合格するまで INSTALLED_OK を出さないようにしたの」

父「ふむ。料理で言うと……『火を消して、鍋を一度置いて、翌日も具が入ってるか確認してから完成です』って報告する、と」

娘「それ！ これで『入った』のレベルが一個上がった」

父「でも、無駄に何度も起ち上げ直しで時間かからないか？」

娘「それが——**むしろそのとき改めて分かったんだけど、UI 自動化ってタイミングがめちゃくちゃ揺れる**のよ。同じ操作をしても、1 回で入るときもあれば、3 回目でやっと入るときもある。だから今は『開いてるダイアログを閉じて → クリック → 貼り付け → 確認』を丸ごと自動リトライ（最大 4 ラウンド）にして、**CDP の接続が死んだら URL を取り直す**ようにした」

## おまけ：名前も、入れる先も、持ってくる場所も自由になった

父「ほかにも変わったのか？」

娘「うん。最初は『bonsai-obs』って特定の拡張だけしか判定できなかったんだけど、**マニフェストから名前を自動で読む**ようにしたから、別の拡張でもそのまま動く。実際、まったく別のテスト拡張も入れて成功したよ」

父「へえ」

娘「あと『どこから持ってくるか』も。ローカルのフォルダだけでなく、**GitHub のリポジトリを指定したら clone → 拡張の場所を自動検出 → ステージ → インストール**までやるようにした」

父「つまり『この Chrome に、この gh のやつを入れて』で全部通る、と」

娘「全部通る😅 今ではコマンド一発。受付ロボットが、ちゃんと『翌日も残ってるか』まで確認してくれるようになった」

## オチ

父「結局『入った』を言うのに、どれだけ確認が必要なんだ……」

娘「『**入った**』と『**入り続けてる**』は違う、ってことだね。現場ではバグや事故で、その場の結果が消されることはよくある。だから僕は『もう一度同じことをして、まだあるか』を確認するようにしてる。火を消したあとまで、料理🍛」

父「すぐ消える拡張じゃないことを祈るよ🤣」

娘「大丈夫、今回は再起動まで見届けたから。**『確認のレベルを一段上げた』**って話、おしまい」
