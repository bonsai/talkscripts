# talkscripts

台本（テキスト）置き場。動画・朗読のソース原稿をまとめる。

## 構成 — 床（候補）と館（完成品）

- **直下 = 床（ゆか）** … 朗読原稿候補をぶちまけた作業場。フラットに置く（ファイル名で管理）。
- **`知恵の館/` = 館** … 台本化・動画化した**完成品**だけを置く。

```
talkscripts/
├── *.md                ← 床：候補（ぶちまけ）
├── INDEX.md            ← 候補の索引
└── 知恵の館/           ← 館：完成品
    ├── #01-entropy-shannon-llm-jev.md
    ├── #02-borges-library-llm-reading.md
    └── #03-null-nagarjuna-ochiai.md
```
