# VNC入門 第1回：VNCって何？リモートデスクトップの世界を知る

VNC（Virtual Network Computing）は、離れた場所にあるコンピュータの画面を、自分のパソコンから操作できるリモートデスクトップ技術です。1990年代にイギリスのORL研究所で開発され、"Thin Client"という思想のもと、サーバ側の負荷を最小限に抑えるシンプルな設計になっています。

仕組みは意外と単純です。操作される側に**VNCサーバ**、操作する側に**VNCクライアント**を用意します。サーバは自分の画面を小さな画像データとして分割し、クライアントへ送信します。クライアントはマウスやキーボードの操作をサーバへ返送。これだけのやり取りで、遠隔地のデスクトップがまるで手元にあるかのように動くのです。

VNCの大きな特徴は、RFB（Remote Frame Buffer）という独自プロトコルを使い、**OSの種類を問わず動作する**点です。Windows・macOS・Linuxはもちろん、Raspberry Piやスマートフォンまで接続先にできます。これは「どの環境でも同じプロトコルで繋がる」というVNC誕生の理念そのもの。企業の自宅勤務支援から、IoT機器のメンテナンスまで、活用範囲は広いと言えます。

一方で、画面全体を画像で送る特性上、RDP（Windows標準のリモート接続）と比べるとどうしても通信量が多く、回線が細いと操作がもたつく傾向があります。それでも、クロスプラットフォーム対応の柔軟さと、少ないリソースで動く手軽さは大きな魅力です。
